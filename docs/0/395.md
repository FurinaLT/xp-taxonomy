“黑色胶带计划”是由迈阿密设计师乔尔·阿尔瓦雷斯创作的一项开创性艺术项目。该项目主要内容是用剪裁粘贴的[胶带](https://dic.pixiv.net/a/%E3%83%80%E3%82%AF%E3%83%88%E3%83%86%E3%83%BC%E3%83%97)装饰裸体。

这种时尚风格起源于2017年左右的迈阿密，不仅在时装秀上，也在角色扮演等活动中越来越受欢迎。其创始人乔尔·阿尔瓦雷斯将其描述为对停滞不前的时尚产业的一种反抗。
