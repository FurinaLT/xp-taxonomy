## 描述

Dom/Sub 宇宙，如同 [Omegaverse](https://dic.pixiv.net/a/%E3%82%AA%E3%83%A1%E3%82%AC%E3%83%90%E3%83%BC%E3%82%B9) 一样，是一种主要出现在 [BL](https://dic.pixiv.net/a/BL) 同人小说中的特殊设定（尽管它也可用于 [NL](https://dic.pixiv.net/a/NL) 和 [GL](https://dic.pixiv.net/a/GL) ）。简而言之，这是一个关于支配/臣服的世界。它起源于海外同人小说。这种设定将现实世界 [BDSM](https://dic.pixiv.net/a/BDSM) 中的支配/臣服性偏好融入到性别概念中。[^1]
