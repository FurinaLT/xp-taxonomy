这指的是除了[书包](https://dic.pixiv.net/a/%E3%83%A9%E3%83%B3%E3%83%89%E3%82%BB%E3%83%AB)之外全身赤裸的状态。许多[插图](https://dic.pixiv.net/a/%E3%82%A4%E3%83%A9%E3%82%B9%E3%83%88)也描绘了穿着袜子或及膝袜的角色。书包通常是[小学生](https://dic.pixiv.net/a/%E5%B0%8F%E5%AD%A6%E7%94%9F)使用的，这使得它成为众多“ [裸体[某物]](https://dic.pixiv.net/a/%E8%A3%B8%E2%97%8B%E2%97%8B) ”标签中最危险的[标签](https://dic.pixiv.net/a/%E3%82%BF%E3%82%B0)之一。[^1]
