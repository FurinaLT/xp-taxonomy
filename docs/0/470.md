这指的是事物呈现出与现有[常识](https://dic.pixiv.net/a/%E4%B8%80%E8%88%AC%E5%B8%B8%E8%AD%98)完全不同的形式，或者人们采取的行动与常识完全不同，但他们却认为这些是“新的[常识](https://dic.pixiv.net/a/%E5%B8%B8%E8%AD%98) ”。与被认为[是非常规的](https://dic.pixiv.net/a/%E9%9D%9E%E5%B8%B8%E8%AD%98)事物不同，这个标签用于观众可能会觉得有说服力或点头同意的事物，心想“这是可以接受的”。[^1]
