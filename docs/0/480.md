“冷脸萌”指一种高冷与呆萌交织的强烈反差魅力。[^2]需满足两大条件：反差张力：冷漠外表需与柔和元素（如幼态五官、玩偶配饰）或温暖行为（如猫咪尾巴缠绕主人）形成冲突；  自然流露：非刻意摆拍，而是内在气质（外冷内热）与外在形象的统一，例如暴雨中守护投喂者的流浪猫表面冷漠实则守信。[^1]

(不过为什么日语翻译为“酷娇”……)

典型的冷漠内敛的人不爱说话，不轻易表露情感，甚至难以表达。然而，一旦与心仪之人亲近，便会变得非常温柔体贴，展现出可爱的一面，流露出对对方炽热的爱意。与傲娇型人格不同，他们面对除心仪对象之外的其他人时，往往冷漠而拘谨。这种表里不一的形象被视为一种 [“萌”的](https://dic.pixiv.net/a/%E8%90%8C%E3%81%88)[特质](https://dic.pixiv.net/a/%E5%B1%9E%E6%80%A7) 。[^3]
