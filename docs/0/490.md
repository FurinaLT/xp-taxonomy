“萝莉老太婆”一般有两种理解，一种是指虽然外表是萝莉但精神很老成的角色，有很强烈的反差萌。比如《全职法师》的灵灵。

而另一种是指外表萝莉体型，但真实年龄很大（达到了老太婆甚至老妖怪的标准），说话做事也老气横秋，或有一种经历过沧桑的和年龄不符的成熟稳重感。最具代表性的角色就是大家都很熟悉的天山童姥了。
