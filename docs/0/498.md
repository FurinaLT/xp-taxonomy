## 描述

溺水，亦称浸没、淹没或淹溺，是一种因人体浸没于液体（如水）导致呼吸障碍的过程。在ICD-11编码系统中，该类目被分类为NF08.1，属于“某些特指外因的效应”类目下的一个具体实例。[^1]

[^1]: [条目-溺水或非致命淹溺-NF08.1-定义与概况 - 家医大健康](https://www.familydoctor.cn/icd11/injuries/drowningnonfatal-submersion.html). 2026-07-19
