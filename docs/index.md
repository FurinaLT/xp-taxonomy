不需要我多说了吧，现在我简单解释一下搜索和目录功能：

- **目录**：电脑网页版可直接切换目录，手机网页点击左上角三条杠展开目录。
- **搜索**：屏幕正上方的搜索按钮，输入后点击右侧分享按钮可分享当前搜索内容
- **图谱**：电脑网页版右侧目录下方就是图谱，手机版点击右上方图谱按钮可查看图谱

本项目的初衷是尽可能收集目前所有的XP，并给予分类，你可以把本项目当做一个OC参考字典，或者只是增长知识使用。
